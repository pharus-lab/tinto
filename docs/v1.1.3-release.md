# Tinto v1.1.3 release record

The first release with Linux installers: Ubuntu and Debian on amd64 and arm64, beside the macOS installer. It carries the Linux work prepared and tested on Linux by Juan Pablo Rubio as a 1.1.2 release candidate, renumbered 1.1.3 because 1.1.2 was published for macOS first. Same format as [the v1.1.2 record](v1.1.2-release.md).

## Release decisions

- **Every platform in one release.** Tinto's update notice follows the latest release, so 1.1.3 carries the macOS installer too. It includes the Linux candidate's shared fixes: a failed save keeps pending typing evidence for retry, renaming the active project keeps later authorship records, and a failure to remember open tabs does not block the final save.
- **Linux checks on Linux computers.** The Linux candidate (main at `d00ada0`) was tested on Linux by its author before this release, as the v1.1 decision requires ([Linux validation](v1.1-release.md#linux-validation-deferred-to-actual-linux)). Since then, main gained only the platform-neutral 1.1.2 changes (the writing coach's notes and the usage estimate), which pass the full suite.
- **One app for every platform.** The macOS app and both Linux apps contain the same `app.asar` (SHA-256 `f2ca46ca5e2238cd532815a4d1da986e1604d0e3bc4f2e4322e472ea7a12776f`); the platforms differ only in the official, checksum-verified Electron 45.4.1 runtime.

### Linux installers

Built on **2026-11-23** from the release commit: `npm run package -- linux x64` and `npm run package -- linux arm64` (Electron's cross-platform packaging), then `scripts/linux-deb.sh amd64` and `scripts/linux-deb.sh arm64` in a Debian 12 container with Node.js 24. The script checks that each app's version and ELF architecture match the package.

Each `.deb` was then installed with `apt` on a clean Ubuntu 24.04 container of its architecture:

| Check | arm64 | amd64 |
| --- | --- | --- |
| `apt install` resolves its dependencies; `dpkg-query` reports `tinto 1.1.3` | Passed | Passed |
| `chrome-sandbox` owned by root with mode 4755; desktop entry, icon and `/usr/bin/tinto` launcher | Passed | Passed |
| Writing worker and Pandoc unpacked beside the archive | Passed | Passed |
| Launch on a virtual display (Xvfb): runs until stopped and writes its profile, including Local Storage | Passed | Not checked: under x86-64 emulation on Apple silicon, Chromium's zygote process crashes before any app code runs; `tinto --version` succeeds |

These container checks confirm the packages; the desktop behavior (sessions, keyring, Wayland) was validated on Linux computers with the candidate.
